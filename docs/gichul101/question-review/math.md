# gichul101 중1 수학 검토 (math__ 15개 파일)

## 요약
- **문항 수**: 324문항 (단원평가 9세트 × 20문항 + 2학기 중간·기말 대비 6세트 × 24문항). 전 페이지를 렌더링해 그림까지 보고, 모든 문항을 먼저 직접 푼 뒤 정답지와 대조함.
- **전반 평가**: 324문항 중 **정답 오류, 복수 정답, 조건 부족은 한 건도 없음**. 그래프와 도형 그림(좌표평면, 쌍곡선, 히스토그램, 도수분포다각형, 평행선 각도, 전개도, 접은 종이)도 주어진 수치와 맞고, 각도 그림은 실측해도 거의 축척대로임(예: 중간1 02번 70°, 21번 70°/55°). 배점 합계는 15개 모두 100점이고, 정답 번호 분포도 고름(①48·②46·③49·④52·⑤51).
  다만 모든 세트가 같은 틀로 찍혀 나와 문항 구성과 유형이 반복되고, '상' 문항도 대부분 교과서 '중' 수준임. 그래서 상위권을 가르는 내신 고난도 문항에 대한 대비는 약함. 해설은 정확하고 간결하며, 일부는 오답 선지가 나온 실수까지 짚어 줌(문자와 식 14번 "①은 −2×(−3)을 −6으로 잘못 계산"). 다만 중간·기말 서술형 채점 포인트에는 부분점수 배분이 빠져 있음.
- **교육과정**: 2022 개정 중1 순서를 따름(대푯값이 중1 2학기 기말 범위에 들어 있음. 2015 개정에서는 중3 내용). 1학기는 소인수분해 → 정수와 유리수 → 문자와 식 → 일차방정식 → 좌표평면과 그래프(정비례·반비례), 2학기 중간은 기본 도형 ~ 원과 부채꼴, 기말은 원과 부채꼴 ~ 자료의 정리와 해석. 범위를 벗어난 문항은 없음.
- **점수**: 정확성 **9.5/10** · 실전성 **7/10** · 해설 품질 **7/10**

## 공통 패턴 · 제작 개선 제안
1. **난이도 상한이 낮음**: '상' 표시 문항 상당수가 한두 단계짜리 대입·계산임(정수와 유리수 07·10, 문자와 식 07·08, 일차방정식 03, 좌표평면 05, 최대공약수 11, 기말1 03). 세트마다 1~2문항은 실제 내신 변별용 수준으로 넣기를 권함. 예: "해가 자연수가 되도록 하는 a의 개수", 절댓값 조건이 여러 개 걸린 정수 문제, 겹친 도형의 넓이, 도수분포표의 빈칸을 두 조건으로 구하는 문제.
2. **틀이 완전히 같음**: 단원평가 9개가 모두 "객관식 14 · 단답 3 · 서술형 3, 5점짜리 3개, 18번 9점, 19·20번 10점"이고, 부제도 모두 "~부터 ~까지" 형식임. 중간·기말 6개도 배점 배치가 같음. 중간 22번에 SAS 합동 설명(1·3회), 24번에 부채꼴이 들어가는 식으로 같은 번호에 같은 유형이 반복됨. 회전체 단면은 기말 세 세트 모두에, 다각형 대각선 개수와 n(n−1)/2 유형은 중간 세트마다 나옴. 세트별로 유형 배치를 섞기를 권함.
3. **서술형 채점 기준 통일**: 단원평가처럼 중간·기말 서술형에도 단계별 부분점수를 표기하면 자가 채점과 서술형 감점 대비에 실제로 도움이 됨.
4. **오답 선지**: 대부분 부호 실수, 역수 누락, 이항 부호, 반직선 방향처럼 실제 실수를 바탕으로 잘 만들었음. 다만 몇 개는 아무도 고르지 않을 선지임(정수와 유리수 13 ⑤, 중간1 19 ⑤). 해설에서 "①은 ~로 잘못 계산한 값"처럼 오답 원인을 밝히는 방식(현재 일부에만 있음)을 전 문항으로 넓히기를 권함.
5. **그래프 눈금 라벨**: 좌표평면 그림에서 눈금 숫자가 격자선과 겹치거나 점 라벨에 붙어 읽기 혼동이 생김(좌표평면 03). 라벨 배경을 처리하고 위치를 조정하기를 권함.
6. **'이 세트 한눈에 보기'**: 단원평가는 항목이 "1 정수와 유리수" 하나뿐이라 의미가 없음. 소단원(예: 정수와 유리수 / 수직선 / 절댓값 / 대소 관계)과 문항 번호를 함께 적으면 오답 분석용으로 쓸 수 있음.
