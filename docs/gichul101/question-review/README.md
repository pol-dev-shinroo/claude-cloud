## 결론: 정답은 정확하다. 약점은 "같은 틀로 찍어낸" 실전성

정답 정확도는 시중 무료 자료보다 확실히 높습니다. 3,900문항 중 채점 오류는 2건뿐이고, 둘 다 직접 다시 확인했습니다. 해설에 오답 이유와 서술형 채점 포인트가 있는 것도 큰 장점입니다.

문제는 학생·교사가 몇 장만 넘겨 봐도 보이는 **반복과 틀**입니다.

1. **모든 세트가 같은 번호 배치**: 영문법 33단원은 07 개수 세기, 08 두 곳 고치기, 24 표, 28 조건 영작…이 매번 같은 자리에 나옵니다. 교과서 32개 과는 01 영영풀이, 03 다의어…, 수학 단원평가는 모두 "객관식 14·단답 3·서술형 3"입니다.
2. **교과서 사이에 같은 문항 복제**: 이름과 단어만 바꾼 동일 구조 문항이 4개 교과서에 반복됩니다. 예: when 의문사·접속사 구분이 4종 모두 15번.
3. **답이 보이는 함정**: '짝이 틀린 것'은 16개 과 모두 반대말 선지가 정답입니다. '답할 수 없는 질문'은 거의 항상 가격·시간·개수입니다. 대화 흐름 문항은 never로 뒤집은 문장이 정답입니다. 패턴만 알면 찍을 수 있습니다.
4. **예상문제 100의 중복**: 신규 40문항은 8세트 모두 같은 번호, 같은 발문입니다. 해당 과 30문항 세트에서 그대로 옮긴 비율은 다음과 같습니다.
   - 4종 교과서(천재 이상기·천재 소영순·동아 이병민·NE능률 김기택): 60문항 100% 재수록
   - 윤정미·박준언: 세트당 54~56문항 재수록, 전체의 55%
   - 30문항 세트를 이미 푼 학생에게는 절반 이상이 반복입니다.
5. **'상' 라벨 과대**: 형식(모두 고르기, 개수 세기) 때문에 '상'이 붙은 경우가 많고, 상위권을 가르는 진짜 고난도 문항은 거의 없습니다. 영어는 글 순서 배열, 무관한 문장, 주제·제목 유형이 없어서 실제 학교 시험보다 한 단계 쉽습니다.
6. **고정 인물·범례 미사용**: 같은 이름(Jun, Jiho, Ben, Yuna, Mia…)이 세트마다 40~80번씩 나옵니다. 범례의 "자주 출제" 표시는 800문항 중 실제로 쓰인 곳이 0곳입니다.

## 제작 방식 개선 제안

1. **틀 섞기**: 세트마다 문항 순서와 유형 배치를 바꾸고, 정답이 패턴으로 보이지 않게 함정 종류를 돌려 쓰기.
2. **실제 시험 형식 추가**: 예상문제 100은 "실전 모의고사 3회분(회당 25~28문항, 배점, 서술형 30~40%)"으로 재구성. 사이트 설명도 "재수록 60 + 신규 40"처럼 실제 구성대로 표기.
3. **진짜 고난도 1~2문항**: 영어는 글 순서, 무관한 문장, 어법 개수, 통합형 서술형. 수학은 세트당 변별 문항.
4. **난이도 기준 재정의**: 형식이 아니라 풀이 단계 수와 함정 수로 상·중·하를 매기기.
5. **해설 보강**: 영문법 Unit 23–33처럼 한 줄 해설이 많은 단원은 Unit 28 수준(함정, 해석, 별해)으로. 수학 중간·기말 서술형에는 단계별 부분점수 추가.
6. **인물·소재 다양화**: 이름 풀을 넓히고 교과서마다 다른 소재를 쓰기. AI로 만든 느낌을 줄이는 데 가장 효과가 큽니다.
