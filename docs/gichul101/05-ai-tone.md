# 05. "AI가 만든 것 같은" 느낌 점검

사이트 전 페이지(257개)의 본문 문장을 모아 반복 횟수를 셌고, PDF 문항 검토 결과(`question-review/`)와 경쟁 사이트·블로그 표현을 함께 비교했습니다.
경쟁사 표현은 웹 검색 결과 기준이며, 검색량으로 검증한 문구 교체안은 `04-keywords-copy.md`에서 확정합니다.

## 1. 해명 문구가 거의 모든 페이지에 반복됨 (가장 큰 신호)

| 문장 | 나오는 페이지 수 |
|---|---|
| 학교 기출문제에 자주 나오는 유형을 분석해 이 과의 내용으로 새로 만든 문제입니다. 실제 학교 시험지를 옮긴 것은 아닙니다. | 64 |
| 학교 시험에 나오는 형태로 직접 만든 문제지입니다. 다른 교재의 문제를 옮긴 것이 아닙니다. … | 33 |
| 교과서의 의사소통 기능과 언어 형식을 바탕으로 직접 만든 문제지입니다. 교과서 출판사와는 관계가 없습니다. … | 32 |
| (유사 문장 2종) … 새로 만든 예상문제입니다. 실제 학교 시험지를 옮긴 것은 아닙니다. | 33 |
| 푸터: 모든 문제는 직접 만들었습니다. | 257 |

사람이 운영하는 자료 사이트는 묻지 않은 해명을 페이지마다 하지 않습니다. 같은 해명이 반복되면 오히려 "뭔가 숨기나?", "자동으로 찍어낸 페이지인가?"로 읽힙니다.

**제안**: 저작권·출처 안내는 `이용 안내` 한 곳과 푸터 한 줄로 충분합니다. 각 페이지 상단은 그 자료의 내용(범위, 문항 수, 난이도, 언제 풀면 좋은지)으로 채우세요.

## 2. 랜딩 페이지 템플릿 그대로인 블록

- `Contents 01` ~ `Contents 04` 영문 번호 + 해시태그 줄(`#과별문제 #의사소통 #문법 #서술형 #정답과해설`) + 명령형 한 줄(`학교 시험 전에 배운 과를 한 번에 점검하세요.`)이 네 번 똑같은 틀로 반복됩니다.
- 숫자 띠 `33단원 / 63세트 / 0원 / 가입 없음`도 흔한 템플릿 구성입니다.
- 문장 끝이 거의 모두 `~하세요 / ~보세요`(받아 보세요, 점검하세요, 확인하세요, 풀어 보세요)입니다.

**제안**: 해시태그 줄 삭제. "Contents 01" 같은 영문 장식 대신 실제 쓰임을 보여 주세요. 예: "시험 2주 전: 과별 30문항으로 범위 훑기 → 1주 전: 예상문제 100으로 마무리". 명령형은 버튼 한 곳에만.

## 3. "기출"이라는 이름과 실제 내용의 어긋남

사이트 이름과 제목에 "기출"이 들어가지만, 본문은 계속 "실제 기출이 아니다"라고 설명합니다. 경쟁 서비스에서 "기출"은 **실제 학교 시험지**(족보닷컴 "학교별 기출 무료열람실", 내신코치 "학교별 기출")를 뜻합니다. 기출을 찾아온 사람은 실망하고, 이를 막으려고 해명이 늘어난 것으로 보입니다.

같은 성격의 자료를 다른 곳에서는 이렇게 부릅니다(검색 결과에서 확인한 표현):
- 영어과외TV: "중1 동아 윤정미 1과 **본문 변형 문제**", "전단원 단어, **학습지**"
- Scribd 업로드 자료명: "중1 동아 (윤정미) 1과 **기출100**", "1과 **기출문제 문법편**"
- 내신코치: "**적중문제**", "**핵심정리**", "**심화서술**"
- 출판사 상품: "**평가문제집**", "**특급기출**"

**제안**: "기출 유형 예상문제"를 "**예상문제** / **변형문제**" 중심으로 바꾸고, 사이트 소개에서 "기출 101 = 기출 경향을 반영한 예상문제"라고 한 번만 정의하세요. 어떤 단어를 앞세울지는 검색량으로 결정(04 문서).

## 4. 문제지 안의 기계적인 반복 (문항 검토 결과)

문항 검토 에이전트들이 공통으로 지적한 점입니다.
- 모든 단원·과가 **문항 번호별 유형까지 똑같은 틀**입니다(영문법 11개 단원 모두 07 개수 세기, 08 두 곳 고치기, 24 표, 28 조건 영작 …; 교과서 8개 과 모두 01 영영풀이, 03 다의어 …).
- 같은 이름의 인물이 단원마다 돌아가며 나옵니다.
- 범례의 "자주 출제" 표시가 실제 문항에는 한 번도 쓰이지 않습니다(동아 윤정미).
- 내용 일치 오답이 본문에 없는 정보라 바로 걸러집니다.

정답 정확도는 높지만, 학생·교사가 몇 장만 넘겨 봐도 "같은 틀로 찍어낸 문제"라는 인상을 받습니다. 개선 방향은 `question-review/README.md`에 정리합니다.

## 5. 사람이 운영한다는 신호가 없음

AI 생성 사이트처럼 보이지 않게 하는 가장 확실한 방법은 문구 교체보다 **사람의 흔적**입니다.

| 추가할 것 | 예 |
|---|---|
| 만든 사람 소개 | "중등 영어 지도 N년, ○○에서 수업" 정도의 한 줄 + 왜 무료로 만드는지 |
| 수정 기록 | "10/12 동아 윤정미 3과 23번 해설 수정 (제보 감사합니다)" — 오류를 고친다는 증거 |
| 실제 날짜가 있는 공지 | 지금 공지는 날짜 없이 한 줄 |
| 학생·선생님 제보·후기 | 받은 메일 중 허락받은 것 |
| `since 2026` 삭제 | 올해 만든 사이트라는 점만 강조됨 |
