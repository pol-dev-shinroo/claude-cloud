# 02. 로그인 (이메일 인증) 설계안

## 먼저 정할 것: 다운로드는 계속 로그인 없이

경쟁 사이트는 모두 가입을 요구합니다.

- 족보닷컴: 무료 열람도 회원만 가능하고, 본인 학교 자료만 보입니다. 인쇄는 유료입니다.
- 내신코치: 무료 다운로드에 회원가입과 휴대폰 인증이 필요하고 하루 횟수 제한이 있습니다.
- EXAM4YOU: 정회원에게만 무료입니다.

기출 101의 "가입 없이 바로 PDF"는 이 사이트들과 가장 크게 다른 점입니다. 그래서 **로그인은 선택 기능으로 붙이고, PDF 다운로드와 정답 보기에는 절대 로그인을 요구하지 않는 것**을 원칙으로 제안합니다.

로그인은 "하면 더 편한 것"이 있어야 사람들이 합니다. 로그인하면 열리는 기능 후보:

| 기능 | 설명 | 로그인 없이 대안 |
|---|---|---|
| 내 교과서·학교 저장 | 어느 기기에서든 홈에 내 교과서 바로 표시 | localStorage (그 기기만) |
| 채점 기록·오답 노트 | 웹에서 답 입력 → 점수와 틀린 문항 저장 | 없음 |
| 출시·업데이트 알림 | "준비 중" 교과서, 내 시험 범위 새 자료 메일 | 없음 |
| 오류 신고 내역 | 신고한 오류가 고쳐졌는지 확인 | 없음 |

## 반드시 확인할 것: 만 14세 미만 (중1 대부분)

2026년 중1은 대부분 2013년생이라 만 12~13세입니다. 개인정보 보호법은 **만 14세 미만 아동의 개인정보를 처리할 때 법정대리인(보호자) 동의**를 받고, 실제로 동의했는지 확인하도록 정하고 있습니다. 이메일 주소도 개인정보입니다.
(제22조의2 아동의 개인정보 보호. 같은 조항에 따라 보호자 동의를 받는 데 필요한 최소 정보는 아동에게서 직접 받을 수 있습니다.)

따라서 "이메일 인증만 하는 가입"은 중1 학생에게 그대로 쓰면 안 됩니다. 가입 흐름에 다음이 필요합니다.

1. 가입 첫 단계에서 출생 연도(또는 "만 14세 이상인가요?")를 묻는다.
2. 14세 미만이면 보호자 이메일을 받아, 보호자에게 동의 메일을 보내고 보호자가 링크를 눌러 동의해야 계정이 활성화된다.
3. 보호자 동의 전에는 학생 이메일과 보호자 이메일 외에는 아무것도 저장하지 않고, 일정 기간(예: 7일) 안에 동의가 없으면 삭제한다.
4. 개인정보처리방침에 수집 항목, 목적, 보유 기간, 14세 미만 처리 방법, 탈퇴 방법을 추가한다.

> 확인 필요: 보호자 동의 "확인 방법"으로 전자우편 방식이 인정되는지(시행령 제17조의2), 최신 조문을 법제처 국가법령정보센터와 개인정보보호위원회 「아동·청소년 개인정보 보호 가이드라인」에서 출시 전에 직접 확인하세요. 이번 점검에서 검색으로는 원문을 확인하지 못했습니다. 운영 규모가 커지면 전문가 검토를 받는 것이 안전합니다.

이 부담 때문에 아래 순서를 추천합니다.

- **1단계 (가입 없음)**: localStorage로 "내 교과서 기억", "최근 본 자료", "정답 가리기 설정". 개인정보 수집 0. 효과의 대부분을 여기서 얻습니다.
- **2단계 (알림 신청만)**: "출시 알림" 이메일만 받기. 계정 없이 이메일 + 수신 동의. 14세 미만이면 보호자 이메일로 신청하도록 안내.
- **3단계 (정식 로그인)**: 채점 기록·오답 노트를 만들 때 도입.

## 로그인 흐름 (3단계 기준)

비밀번호 없이 이메일로 받은 **6자리 인증 코드**를 입력하는 방식을 추천합니다.

- 학생 대부분이 휴대폰을 씁니다. 메일 앱의 링크를 누르면 다른 브라우저(앱 내 브라우저)가 열려 로그인이 끊기는 일이 잦습니다. 코드 입력은 이 문제가 없습니다.
- 비밀번호를 저장하지 않으니 유출 위험과 "비밀번호 찾기" 기능이 필요 없습니다.

```
이메일 입력 → [출생 연도] → 6자리 코드 발송 → 코드 입력
   └ 14세 미만: 보호자 이메일 입력 → 보호자 동의 메일 → 보호자 클릭 → 활성화
```

세부 규칙:

| 항목 | 값 |
|---|---|
| 코드 유효 시간 | 10분 |
| 재발송 | 60초 후 가능, 시간당 5회 |
| 코드 입력 실패 | 5회 실패 시 새 코드 필요 |
| 오류 문구 | "코드가 맞지 않거나 시간이 지났어요. 새 코드를 받아 주세요." (계정 존재 여부를 드러내지 않기) |
| 로그인 유지 | 30일, "이 기기에서 로그인 유지" 체크 |
| 안내 | "메일이 안 오면 스팸함을 확인해 주세요. 네이버 메일은 1~2분 걸릴 수 있어요." |

메일 도달률: 한국 학생·학부모는 네이버 메일과 다음 메일을 많이 씁니다. 발송 도메인에 SPF, DKIM, DMARC를 설정해야 스팸함으로 가지 않습니다.

## 구현 방법

현재 사이트는 Cloudflare 뒤의 정적 HTML입니다. 서버를 새로 운영하지 않는 방법이 맞습니다.

| 방법 | 장점 | 단점 |
|---|---|---|
| Supabase Auth (이메일 OTP) | 코드 발송·검증·세션이 기본 제공, 무료 구간 넉넉함 | 보호자 동의 흐름은 직접 구현 |
| Cloudflare Workers + D1 + 메일 발송 API(Resend, AWS SES 등) | 지금 인프라(Cloudflare) 그대로 | 인증 로직을 직접 작성 |
| 카카오·네이버 로그인 | 학생·학부모 대부분 계정 보유, 가입 마찰 최소 | 앱 검수 절차 있음, 14세 미만 처리 정책 확인 필요 |

추천: Supabase Auth 이메일 OTP로 시작하고, 사용자가 늘면 카카오 로그인을 추가합니다.

## 출시 전 체크리스트

- [ ] PDF 다운로드·정답 보기에 로그인 요구 없음 확인
- [ ] 14세 미만 보호자 동의 흐름 + 미동의 계정 자동 삭제
- [ ] 개인정보처리방침 개정 (수집 항목·목적·보유 기간·위탁 업체(메일 발송, Supabase 등)·탈퇴)
- [ ] 회원 탈퇴 = 즉시 삭제 버튼
- [ ] SPF/DKIM/DMARC, 네이버·다음·Gmail로 발송 테스트
- [ ] 코드 발송 API에 IP·이메일당 요청 제한
