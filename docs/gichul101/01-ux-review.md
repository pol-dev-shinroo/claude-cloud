# 01. UX 점검 결과

- 점검일: 2026-10-10
- 범위: 사이트맵의 257페이지 전체 (홈, 교과서별 내신대비, 중간·기말 대비, 중1 영문법, 중1 수학, 소개/이용 안내/문의/개인정보처리방침, 404)
- 방법: Chromium(Playwright)으로 전 페이지 접속. 데스크톱 1366px, 모바일 390px·360px 화면 캡처. 메뉴·다운로드·탭은 직접 눌러서 확인.

## 잘 되어 있는 점

| 항목 | 확인 결과 |
|---|---|
| 응답 | 257페이지 모두 200, 깨진 내부 링크 없음 |
| 검색 노출 기본 | 페이지마다 고유 title, meta description, canonical, JSON-LD, 빵부스러기 있음 |
| 다운로드 | 가입 없이 바로 받음. 미리보기 3장, 문항 구성표, 파일명·쪽수·용량 표시 |
| 페이지 연결 | 하단 "다른 과 / 다음 단원 / 이어서 공부하기", 404 페이지 안내 링크 |
| 접근성 | img alt 누락 0건, 탭 키보드 조작, prefers-reduced-motion 대응 |

## 우선순위 높음

### 1. 모바일 ☰ 버튼이 메뉴를 열지 않고 푸터로 이동함
- 현재: `<a class="menu-btn" href="#site-menu">` → `<footer id="site-menu">`. 360px에서 눌러 보니 페이지 높이 4154px 중 3374px 지점으로 스크롤됨.
- 사용자는 메뉴 패널이 열리길 기대하고 누름. 맨 아래로 튕기면 "고장 났다"고 느낌.
- 제안: 오른쪽에서 열리는 메뉴 패널(교과서 목록, 중간·기말, 영문법, 수학, 문의). 또는 아래 탭 메뉴가 이미 있으니 버튼 제거.
- 같은 문제: 모바일 탭 메뉴(`.subnav__in` scrollWidth 394 > 360)에서 "중1 수학"이 잘리고 가로 스크롤 표시가 없음. 홈 "콘텐츠 소개" 탭도 4번째 "정답과 해설"이 화면 밖. → 라벨 줄이기("교과서별 / 중간·기말 / 영문법 / 수학") 또는 오른쪽 끝 페이드.

### 2. 홈 첫 화면에 행동이 없음
- 모바일 첫 화면 = 제목 + 문단 + 문제지 이미지. 핵심 행동인 "내 교과서 선택"은 스크롤해야 보임.
- 제안: 교과서 버튼 6개를 첫 화면으로 올리기. 문단은 한 줄로 줄이기.

### 3. 홈 버튼이 이름과 다른 곳으로 감
| 버튼 | 실제 이동 | 문제 |
|---|---|---|
| PDF 무료 다운로드 + | `/math/g1/u09-1/` (수학 정비례와 반비례) | 영어 교과서를 찾던 학생에게 엉뚱한 자료 |
| 이용 안내 ↗ | `/terms/` (이용 범위·저작권 안내) | "사용 방법"으로 읽히는 이름 |
| 히어로 문제지 이미지 | `/math/g1/u09-1/` | 같은 문제 |
- 제안: 다운로드 버튼은 "내 교과서 찾기"(`/textbook/`)로, "이용 안내"는 "이용 범위"로 이름 변경 또는 링크 제거.

### 4. 시기(10월 = 2학기 기말 대비)와 순서가 맞지 않음
- 히어로 "2학기 기말고사 대비 자료 업데이트" ↔ 공지 "중1 수학 1학기 단원평가 9개 추가".
- 수학 페이지: 1학기 단원평가가 맨 위. 중간·기말 페이지: 교과서마다 1학기 중간부터.
- 제안: 현재 시험 범위를 맨 위로, "지금 시험 범위" 배지. 학기 탭(기본값 = 현재 학기).

### 5. 다운로드까지 한 단계가 더 있음
- 과 페이지 "PDF 받으러 가기" → PDF 페이지 → "PDF 무료 다운로드". 교과서 목록의 "PDF" 버튼도 파일이 아니라 페이지로 이동.
- 제안: 과 페이지에 바로 다운로드 버튼(`<a download>`가 이미 있으니 그대로 옮기면 됨). 모바일은 하단 고정 바 "PDF 받기 · 정답".

### 6. 정답이 처음부터 다 보임
- 정답 페이지(`/answers/`)를 열면 모든 답이 노출됨. 페이지 안에 `<details>` 없음.
- 제안: 문항별 "정답 보기" 펼침 + "전체 정답 가리기" 토글. 과 페이지 "맛보기 문제"는 보기를 누르면 바로 정오 표시.

## 우선순위 중간

7. **내 교과서 기억 없음**: 매번 다시 골라야 함. 로그인 없이도 localStorage로 "최근 본 자료: 동아 윤정미 → 7과 이어보기" 가능. (로그인을 붙이면 기기 간 동기화로 확장. `02-login.md` 참고)
8. **중간·기말 페이지가 김**: 6종 교과서를 한 페이지에 나열(데스크톱 3184px). 상단에 교과서 칩 + 학기 필터.
9. **모바일 교과서 페이지 줄 모양 불규칙**: 2과·5과·6과처럼 제목이 길면 PDF/정답 버튼이 다음 줄로 떨어짐. 제목 위, 버튼 아래로 통일.
10. **모바일 과 페이지 상단이 좁음**: 왼쪽 "1과" 배지 때문에 제목·설명이 약 200px 폭에 몰림. 첫 화면이 소개 박스와 면책 문구로 꽉 참. 배지는 제목 위로, 면책 문구는 한 줄 또는 푸터로.
11. **문의가 번거로움**: 이메일이 mailto 링크가 아님. 각 문제지·정답 페이지에 "오류 신고" 버튼(문제지 이름이 제목에 들어간 메일 또는 폼).
12. **"준비 중" 교과서가 막다른 길**: 비상 황종배, YBM 김은형, 미래엔 문영인, 지학사 송미정. "출시 알림 받기"로 수요 파악.
13. **수학과 영어 구성 차이**: 영어는 웹 정답 페이지가 있고 수학은 PDF 안에만 있음. 수학 2학기 단원평가 없음.

## 사소한 것

- 404 페이지에 로고 두 번(헤더 + 큰 로고).
- PDF 페이지 상단에 "중1 영어 문법 · Unit 01 · 문제 PDF"와 "중1 영어 문법 Unit 01"이 연달아 반복.
- 홈 "이용 안내 / PDF 무료 다운로드" 버튼이 데스크톱에서 교과서 버튼과 멀리 떨어져 있어 관계가 안 보임.
- 콘텐츠가 늘면 검색 필요 → `03-search.md`.

## 참고: 크롤링 수치

- 요청 실패는 GA(gtag), 애드센스, Cloudflare 비컨뿐이었고, 점검 환경의 네트워크 차단 때문이라 사이트 문제 아님.
- 페이지 로드(점검 환경 프록시 경유, 실제보다 느림): 중앙값 약 2.0초, 최대 4.4초. HTML은 약 29KB로 가벼움.
