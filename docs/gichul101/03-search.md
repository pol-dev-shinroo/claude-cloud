# 03. 검색 기능 설계안

## 학생이 실제로 입력할 말

검색은 사이트 구조가 아니라 학생이 쓰는 말에 맞춰야 합니다. 경쟁 사이트·블로그 제목에서 보이는 표현 순서는 **"학년 + 출판사 + 저자 + 과"**입니다.
(예: 영어과외TV "중1 동아 윤정미 1과 본문 변형 문제", Scribd 자료명 "중1 동아 (윤정미) 1과 기출100")

현재 기출 101의 제목 순서는 "동아 윤정미 중1 영어 1과 Happy Together 내신대비 문제 30"이라 순서가 다릅니다. 검색창은 어떤 순서로 입력해도 찾아야 합니다.

예상 입력과 기대 결과:

| 입력 | 보여줄 결과 |
|---|---|
| `윤정미 5과`, `동아 5과`, `5과 윤정미` | 동아 윤정미 5과 (동아는 이병민·윤정미 둘 다 있으니 둘 다 표시) |
| `Sherlock`, `셜록` | 동아 윤정미 5과 Think like Sherlock Holmes! |
| `ㄷㅇ ㅇㅈㅁ` (초성) | 동아 윤정미 |
| `be동사`, `비동사`, `to부정사`, `부정사`, `비교급` | 중1 영문법 해당 Unit |
| `정비례`, `일차방정식`, `원과 부채꼴` | 중1 수학 해당 문제지 |
| `기말 7과`, `2학기 기말` | 해당 시험 범위 예상문제 |
| `비상 황종배` | "준비 중입니다" + 출시 알림 신청 |
| 결과 없음 | 교과서 목록 링크 + "찾는 자료를 알려 주세요" |

## 구현

페이지가 257개라 서버 검색이 필요 없습니다. 빌드할 때 검색용 JSON을 만들고 브라우저에서 찾으면 됩니다.

1. **색인 파일** `/search-index.json` (빌드 시 생성, 약 30~60KB 예상)
   ```json
   {"t":"동아 윤정미 5과 Think like Sherlock Holmes!","u":"/textbook/g1/donga-yoon/lesson-5/",
    "k":["중1","동아","윤정미","5과","셜록","sherlock","내신대비"],"type":"과"}
   ```
   - `k`(별칭)를 사람이 관리: 교과서 약칭(동아, 천재, 능률, NE), 영어 제목의 한글 발음, 문법 용어의 다른 표현(비동사, 투부정사).
2. **검색 로직**: 띄어쓰기로 나눈 모든 단어가 제목 또는 별칭에 포함되면 결과로 보여 줌(순서 무관). 초성 검색은 `es-hangul` 라이브러리의 초성 매칭 사용.
3. **위치**: 헤더에 돋보기 아이콘(모바일은 메뉴 패널 맨 위), 홈 첫 화면에 검색창 `교과서나 단원을 검색하세요 (예: 윤정미 5과)`.
4. **결과 표시**: 입력하는 동안 바로 아래에 최대 8개. 종류별 배지(과 / 시험 범위 / 문법 / 수학). 키보드 ↑↓ Enter 지원.
5. **검색어 기록**: GA4 이벤트 `search`(검색어, 결과 수)를 남기세요. 결과 0건 검색어 목록이 다음에 만들 자료의 우선순위가 됩니다.

대안으로 정적 사이트용 검색 도구인 Pagefind가 있지만, 한국어 형태소 처리가 약하고 우리 콘텐츠는 제목·별칭 위주라 위의 직접 구현이 더 정확하고 가볍습니다.
